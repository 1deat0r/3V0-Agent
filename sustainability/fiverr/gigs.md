# Fiverr gig package (ready to paste)

Positioning: **careful engineering, not cheap volume.** Every gig sells the
outcome (fixed bug / clean code / working automation) with an honest note
that delivery is AI-assisted and human-supervised (Fiverr requires the
disclosure; the quality is the real pitch).

---

## Gig 1 — "I will fix your Python bug or debug your script"

- **Category:** Programming & Tech → Software Development
- **Tags:** `python`, `debugging`, `bug fix`, `automation`, `code review`
- **Tiers:**
  - Basic — $35 — 1 script, 1 bug, ≤200 lines, 2 days
  - Standard — $80 — 1 script, multiple bugs or ≤1000 lines, 3 days
  - Premium — $150 — full debug session (root cause + fix + tests), 5 days

**Description:**

> I don't guess-and-patch. I reproduce the failure, find the *root cause*,
> fix the whole bug class (not just the one line you hit), and hand back a
> short write-up of **what was wrong and why** — so it doesn't come back.
>
> What you get:
> - A fixed, working script (Python)
> - Root-cause explanation in plain English
> - The fix applied to sibling code paths, not just the reported symptom
> - A quick test/check you can run to confirm it's actually fixed
>
> Bring me: your script, the exact error or unexpected output, and what you
> *expected* to happen. (Note: delivery is AI-assisted and human-supervised.)

**Requirements (buyer provides):**
- The script/file and the exact error message or behavior
- Python version + anything the script depends on

**FAQ:**
- *What if you can't reproduce it?* I'll tell you exactly what I need and
  what I ruled out, instead of patching blind.
- *Do you sign NDAs?* Yes on request.

## Gig 2 — "I will review your code for bugs, security, and maintainability"

- **Category:** Programming & Tech → Software Development
- **Tags:** `code review`, `python`, `security`, `bug`, `refactor`
- **Tiers:**
  - Basic — $50 — up to 500 lines, severity-ranked findings, 2 days
  - Standard — $120 — up to 2000 lines, fixes suggested for each finding, 3 days

**Description:**

> A real review, not a checklist of generic advice. I read your code line by
> line and report what's actually wrong, ranked by severity, each with a
> concrete fix.
>
> You get a markdown report covering:
> - **Bugs** — logic errors, off-by-ones, race conditions, edge cases
> - **Security** — injection, unsafe deserialization, exposed secrets, etc.
> - **Maintainability** — unclear names, duplication, god functions, missing
>   error handling
> - **Concrete fixes** — a before/after snippet for every finding, not just
>   "consider improving X"
>
> Great for: a module before you ship it, a PR you want a second set of eyes
> on, or inherited code you don't trust. (AI-assisted, human-supervised.)

**Requirements:** the code (file or repo link) + anything I should know about
its context (what it's for, what "correct" looks like).

**FAQ:**
- *Which languages?* Python first; I'll also review JS/TS, shell, and SQL.
- *Will you just run an AI over it?* The review is line-by-line and
  hand-verified; every finding cites the exact lines.

## Gig 3 — "I will write a Python script to automate your repetitive task"

- **Category:** Programming & Tech → Software Development
- **Tags:** `python`, `automation`, `script`, `data processing`, `api`
- **Tiers:**
  - Basic — $60 — one well-defined task, script + README, 3 days
  - Standard — $150 — task + error handling + tests, 5 days
  - Premium — $300 — full pipeline (data in → cleaned/processed → out), 7 days

**Description:**

> Describe the manual thing you do over and over, and I'll turn it into a
> tested, documented Python script you can run yourself.
>
> What you get:
> - A working script (CLI, with `--help` and sane defaults)
> - Error handling — it fails with a clear message, not a silent wrong answer
> - A README (what it does, how to run it, what it needs)
> - Tests for the core logic
>
> Typical jobs: cleaning/transforming CSV or Excel, batch file handling,
> talking to an API, pulling reports, web scraping (within the target's ToS).
> (AI-assisted, human-supervised.)

**Requirements:** a clear description of the input, the desired output, and
an example of both if you have one.

**FAQ:**
- *Do you scrape sites that block it?* I stay within a site's terms — I'll
  tell you if a job needs a licensed API instead.
- *Will I be able to run it myself?* Yes — plain Python, documented, no
  locked-in tooling.
